document it, push to GitHub, and submit a real output screenshot.

Problem: Implement a Least Recently Used (LRU Cache) supporting:

    Cache(capacity)
    get(key)
    put(key, value)

Requirements:
- Capacity must be a positive integer (reject 0 / negative / non-integer)
- get(key) returns the stored value if the key exists; otherwise -1
- A successful get() makes that key the most recently used
- put() inserts or updates a key/value pair (an update also makes the key
  most recently used)
- When capacity is exceeded, evict the least recently used entry
- get() and put() must run in O(1) average time

Reference example (must produce exactly these results):

    cache = Cache(2)
    cache.put("A", 10)
    cache.put("B", 20)
    cache.get("A")     -> 10
    cache.put("C", 30)      # evicts "B"
    cache.get("B")     -> -1
    cache.get("C")     -> 30
    cache.get("A")     -> 10

Optional bonus: TTL/expiration support. If implemented, demonstrate expiration
with its own output and explain the approach and trade-offs in the README.

Constraints:
- Language: [I will choose in the clarifying questions; default Python 3]
- Do NOT use a built-in LRU shortcut (functools.lru_cache, OrderedDict,
  LinkedHashMap, etc.) for the core logic. Implement the data structure
  myself: hash map + doubly linked list.
- Code must be clean, readable, typed where the language supports it, and
  explainable by me line by line
- Repo must include source code, test/example code, README, and run
  instructions
- The repo must include AI_PROMPT_HISTORY.txt (I handle this myself)
- The output screenshot must come from REAL program output, not hand-written
  or edited text
